# 📊 Data Analyzer and Transformer

A simple Python-based console application that allows users to perform basic data analysis and transformation operations on a one-dimensional (1D) dataset. This project demonstrates the use of Python fundamentals such as lists, loops, functions, conditional statements, lambda functions, filtering, sorting, and statistical calculations.

---

## 🚀 Features

- 📥 Input a 1D dataset
- 📋 Display data summary
  - Total number of elements
  - Minimum value
  - Maximum value
  - Sum of all elements
  - Average of the dataset
- 🧮 Calculate the factorial of any number
- 🔍 Filter data based on a user-defined threshold
- 🔃 Sort data
  - Ascending order
  - Descending order
- 📊 Display dataset statistics
- ❌ Exit the program
